# 이음버스 · IeumBus

서울과 인천을 중심으로 버스 도착정보, 정류소와 노선, 승하차 알림을 제공하는 Android 버스 앱입니다. 자주 이용하는 정류소와 버스를 즐겨찾기에 모으고, 지도와 홈 화면 위젯에서 필요한 정보를 확인할 수 있습니다.

Jetpack Compose로 화면을 구성했으며, One UI 스타일의 인터페이스와 넓은 화면에서의 목록·상세 레이아웃을 제공합니다.

## 주요 기능

- **즐겨찾기** — 자주 이용하는 정류소와 버스 노선을 저장하고 도착정보 확인
- **버스·정류소 검색** — 정류소 이름과 번호, 버스 번호를 이용한 검색
- **노선 상세** — 경유 정류소, 운행 방향, 실시간 차량 위치 확인
- **차량 정보** — 제공 데이터에 따라 혼잡도, 잔여좌석, 저상 여부, 막차 정보 표시
- **승차·하차 알림** — 버스 이용 시점에 맞춘 알림 설정
- **지도 검색** — 현재 위치 주변과 지도에서 정류소 탐색
- **홈 화면 위젯** — 앱을 열지 않고 즐겨찾는 버스의 도착정보 확인
- **지역별 공지** — 서울 TOPIS 공지 조회 및 인천버스정보 공지 페이지 연결
- **환경설정** — 이용 지역, 정보 갱신 주기, 서버 연결 상태 확인

기능과 표시 항목은 선택한 지역, 노선 및 공공 API에서 제공하는 데이터에 따라 달라집니다.

## 지원 지역

| 항목 | 서울특별시 | 인천광역시 | 그 외 지역 · 국토부 TAGO |
| --- | --- | --- | --- |
| 즐겨찾기·정류소 검색 | 지원 | 지원 | 제한적 지원 |
| 노선 검색·상세 | 지원 | 지원 | 제한적 지원 |
| 승차·하차 알림 | 지원 대상 노선 | 지원 대상 노선 | 미지원 |
| 혼잡도·차량 정보 | 제공 데이터에 따라 표시 | 제공 데이터에 따라 표시 | 미지원 |
| 공지사항 | TOPIS 공지 목록·상세 | 외부 브라우저로 공지 페이지 연결 | 미지원 |

서울·인천 외 지역은 즐겨찾기와 버스 검색에 한해 제한적으로 지원합니다. 지원되지 않는 노선이 있거나 정보가 누락될 수 있으며, 활성화 전에 앱의 면책조항을 확인해야 합니다.

서울 또는 인천을 선택해도 해당 지역 시내버스 노선이 운행하는 **시계외 구간**, 즉 행정구역 밖의 정류소를 검색할 수 있습니다. 해당 노선의 시계외 정류소를 찾는 목적이라면 확장 지역 기능을 켤 필요가 없습니다.

## 사용 흐름

1. 최초 실행 시 소개 6개를 확인하고 서비스 이용약관·개인정보처리방침·서비스 중요 안내사항에 동의합니다.
2. 다음 권한 안내에서 배터리 최적화 제외·알림·위치·저장공간의 용도를 확인하고 필요한 항목을 활성화합니다. 모든 항목을 허용하지 않아도 **시작하기**로 진행할 수 있습니다.
3. 환경설정에서 이용할 지역을 선택하고 버스·정류소를 검색합니다.
4. 자주 이용하는 항목을 즐겨찾기에 추가하고 지원 노선에서 승하차 알림·위젯을 이용합니다.
5. 데이터 관리에서 지역별 즐겨찾기와 승차알림을 .ieumbus 파일로 백업하거나 복원할 수 있습니다.

커버·일반 화면은 **소개 → 약관 → 권한 안내** 순서로 표시합니다. 펼친 폴더블·태블릿 등 가용 너비가 600dp 이상인 화면은 왼쪽의 시작하기 소개 6개를 유지하고, 오른쪽 패널만 약관 동의에서 권한 안내로 전환합니다. 접기·펼치기 및 화면 크기 변경 시 동의 체크와 화면·스크롤 상태를 유지합니다.

권한의 **활성화 / 비활성화**는 실제 시스템 권한·설정 상태를 표시합니다. 기기 설정에서 돌아오면 다시 조회합니다. 상태 표시는 알림 전달이나 공공데이터의 정확성을 보장하는 표시는 아닙니다. Android 11 이상에서 공유 저장소 폴더를 직접 선택할 때는 **모든 파일 접근**이 필요합니다.

현재 위치로 주변 정류소를 검색하면 조회 좌표가 서울·인천·TAGO 등 해당 제공기관의 API 요청에 포함됩니다. 지도에는 외부 지도 타일 서비스를 사용합니다. 개발자가 별도로 운영하는 위치정보 수집 서버에는 보관하지 않습니다.

## 데이터 백업과 복원

환경설정의 **데이터 관리 → 백업 → 내보낼 파일 선택**에서는 저장 위치와 파일명만 지정합니다. **선택**을 눌러도 파일은 생성하지 않습니다. 앱의 **내보내기**를 눌렀을 때 파일을 만들고 백업 내용을 기록하며, 같은 위치·이름의 파일이 있으면 덮어쓰기 확인을 거칩니다. 기본 위치는 다운로드 폴더(Android 9는 앱 문서 폴더), 기본 파일명은 `IeumBus_Backup_yyyyMMdd_HHmmss.ieumbus`입니다. 즐겨찾기와 승차알림은 중복 ID를 포함해 저장된 목록을 그대로 백업합니다.

**위치 변경**은 시스템 문서 선택창 대신 앱 내 폴더 탐색을 사용합니다. Android 11 이상에서는 앱의 **모든 파일 접근**을 허용한 뒤 다운로드 폴더와 내부 저장소 루트를 포함한 공유 저장소 폴더를 선택할 수 있습니다. Android 9·10에서는 저장소 권한을 요청합니다. 다른 앱의 비공개 폴더 등 Android가 보호하는 경로는 운영체제 제한을 따릅니다.

**복원**에서는 백업 파일을 선택한 뒤 **가져오기**를 실행합니다. 서울·인천·전국의 기존 즐겨찾기 및 승차알림 목록을 교체하며, 현재 검색 지역은 유지합니다.

백업 형식은 `IEUMBUS_BACKUP\n` 헤더와 UTF-8 JSON 본문으로 구성합니다. 본문에는 `backupFormat`, `formatVersion`(현재 1), `appIdentifier`, `createdAt`, `favorites`, `boardingAlarms`가 있습니다. 두 데이터 목록은 각각 `SEOUL`, `INCHEON`, `NATIONWIDE` 키로 지역을 구분합니다. 인증 키·권한·앱 환경설정·하차알림은 포함하지 않습니다.

파일의 백업 형식과 앱 식별자를 확인한 후 복원합니다. 앱에서 임의로 정한 파일 용량·항목 개수·문자 수 제한은 없습니다.

## 데이터 출처와 이용 안내

버스 정보는 서울 버스정보, 서울 TOPIS, 인천 버스정보 및 국토부 TAGO 등 공공 교통 데이터를 기반으로 제공합니다. 지도는 OpenStreetMap 기반으로 표시합니다.

도착 예정 시간과 차량 위치는 교통 상황, 데이터 갱신 지연 및 제공 기관의 서비스 상태에 따라 실제와 다를 수 있습니다. 탑승 전 정류소 안내와 실제 차량의 노선·행선지를 확인해 주세요.

오류를 제보할 때는 이용 지역, 정류소 이름·번호, 노선 번호, 발생 시각과 재현 과정을 함께 알려주시면 원인 확인에 도움이 됩니다. 앱 환경설정의 **서비스 문의 및 오류 제보** 메뉴를 이용할 수 있습니다.
